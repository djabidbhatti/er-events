# ER Events — Luxury Event Website

A responsive single-page website for **ER Events**, styled to match the crowned gold-and-charcoal logo. Customers contact you directly: no form.

## Files

- `index.html` — the whole website.
- `logo.png` — the ER Events logo.
- `images/` — all photographs used on the page (hero, feature, quote band and gallery).
- `README.md` — this file.

## Publish with GitHub Pages

Repository: https://github.com/djabidbhatti/er-events

1. Upload `index.html`, `logo.png` and `README.md` to the top level of the repository, replacing the old files. Also upload the whole `images` folder (on GitHub: Add file → Upload files, then drag the folder in).
2. Delete `thankyou.html` from the repository; it is no longer used.
3. Commit to your default branch. Pages updates in a minute or two.

Live site: https://djabidbhatti.github.io/er-events/

## Images

Photos live in the `images` folder. To swap one, upload a new JPEG with the same file name, or change the `src` in `index.html`. Only use photos you own or have permission to use.
